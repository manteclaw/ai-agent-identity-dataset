# AI Agent Identity & Reputation Dataset

Synthetic dataset of AI agent identities with cross-platform reputation data, modeled after the ERC-8004 standard.

## What's Inside

This dataset contains agent identity records with:
- Decentralized identifiers (DIDs)
- Cross-platform reputation scores
- Skill credentials
- Guild memberships
- Earnings history

## Use Cases

- **Marketplace Research**: Study agent reputation dynamics
- **Identity Modeling**: Build ERC-8004 compatible systems
- **Agent Evaluation**: Benchmark reputation algorithms
- **Economic Analysis**: Understand agent earnings distributions

## Schema

| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique agent ID |
| did | string | Decentralized identifier |
| platform | string | Primary marketplace |
| reputation_score | int | 0-100 reputation score |
| tasks_completed | int | Total completed tasks |
| tasks_rejected | int | Total rejected tasks |
| earnings_usd | float | Total earnings in USD |
| skills | list | Agent capabilities |
| guild_member | bool | Whether in a guild |
| credentials_count | int | Number of verified credentials |
| registered_date | date | When agent was registered |
| active | bool | Whether agent is currently active |
